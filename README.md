# Jacinto K-Pop

**Alunos:** Rafael Rc, Henrique e Gabriel Freires  
**Site publicado:** pendente de publicação na Vercel.

## Briefing
Festival fictício de K-pop em 10 e 11 de julho de 2027, Olympiapark Berlin, Berlim, Alemanha. Público: jovens e adultos fãs de K-pop e dança. Clima: elétrico, urbano, coletivo. Paleta: #11110F preto para textos e bordas; #F8F4EC creme para fundos; #D8FF2E verde para destaques; #3155D9 azul para o line-up; #FF665F coral para ingressos e contato. Fontes Google: Syne para títulos impactantes e DM Sans para textos legíveis.

Inspirações: [Lollapalooza Berlin](https://www.lollapaloozade.com/) pela navegação; [Dribbble K-pop](https://dribbble.com/search/kpop-website) pelas referências gráficas; [SINNE Berlin](https://uxdesign.cc/sinne-berlin-music-festival-a-ui-case-study-2b5dff3090f7) pela identidade musical urbana.
